# voboX

一个轻量的 Windows 桌面音频管理工具，主打**以索引管理音频、不复制文件**，把散落在各处的 WAV 集中组织、搜索、试听和裁剪，可以作为如Melodyne之类的音乐软件的效率软件（不用vst的情况下）。

> 个人项目，仅供娱乐学习

---

## 功能特性

### 导入与组织
- **导入音频**：支持按钮选择或直接拖入（文件 / 整个文件夹均可，文件夹自动镜像子目录结构）
- **只索引不复制**：导入时把外部文件路径登记进索引（`log.txt`），源文件保留原位，不占用额外空间
- **重名检查**：导入时自动检测目标文件夹内的同名音频（含物理文件与索引），避免重复
- **Box 文件夹树**：`Box\voboX` 下可自由建分组，右侧导航悬浮窗一键切换；默认「未分类」文件夹自动维护

### 搜索
- **三种搜索范围**：当前视图 / 全局搜索（整个 Box，排除 tempBox）/ voboX搜索
- **拼音全拼检索**：点右上角「拼」开关开启后，可用全拼搜索中文文件名（如输入 `yinyue` 找「音乐」）
- 搜索时排除文件扩展名，输入 `wav` 不会把所有 .wav 都搜出来

### 播放与波形
- 选中文件即显示波形，支持播放 / 暂停
- 拖动选择波形区间，一键**裁剪保存**

### 拖出到 DAW
- 直接把文件拖出到其他软件（DAW 等）
- 拖出时自动在 **tempBox** 复制一份副本（按时间命名、不自动清理），保证外部软件修改不影响原始文件

### 录音
- 录制屏幕声音，录制来源可在设置中选择设备
- 录音文件自动命名 `yyyyMMdd_HHmmss_record.wav`

### 设置
- 录制来源设备
- 排序规则（时间 / 名称 / 时长，正反序）
- 开机自启动
- 窗口置顶
- 把索引的外部文件实际**拷贝进 voboX**（拷贝后 log 自动移除）

### 界面
- dark主题、默认竖屏窗口
- 自定义标题栏：拖拽移动、置顶、最小化、关闭
- 顶部工具栏按钮均带悬浮提示

## 技术栈

| 组件 | 说明 |
|---|---|
| C# / WPF | .NET 8（`net8.0-windows`） |
| NAudio | 播放、录音、波形提取、裁剪 |
| SQLite (Microsoft.Data.Sqlite) | 音频信息索引 |
| Inno Setup | 安装包制作 |

---

## 安装与使用

1. 下载 `voboX-Setup-1.0.1.exe`（约 48MB，64 位，用户级安装、无需管理员）
2. 安装完成后从开始菜单启动

---

## 数据位置

| 内容 | 路径 |
|---|---|
| Box 音频目录（voboX 分组 / 未分类 / cutBox / recordBox / tempBox） | 随安装目录（`...\voboX\Box`） |
| 设置与数据库 | `%LocalAppData%\voboX`（settings.json + voboX.db，换版本不丢失） |

---
## 说明

- 当前仅支持 **Windows 10/11（64 位）**
- 音频格式支持 **WAV**
- 项目数据基于**索引**，删除 voboX 内的分组不会删除外部源文件；`移除` 操作只会删除 log 索引记录（voboX 内物理文件除外）
